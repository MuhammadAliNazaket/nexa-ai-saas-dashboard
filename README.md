# NexaAI - AI SaaS Dashboard

A modern AI SaaS platform UI designed and developed for portfolio purposes.

## Features

- Responsive SaaS landing page
- AI workspace
- Analytics dashboard
- Automation workflows
- Pricing page
- Authentication UI
- Settings dashboard
- Responsive design

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Chart.js
